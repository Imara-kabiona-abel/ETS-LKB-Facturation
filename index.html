Informations de l'entreprise

Ces informations apparaissent sur tous vos devis, commandes, bons de livraison et factures.

Sauvegarde de vos données

Toutes vos données (documents, catalogue, clients) sont stockées uniquement sur cet appareil, dans ce navigateur. Elles ne se transfèrent pas automatiquement entre votre PC et votre téléphone. Utilisez cette sauvegarde pour les transporter d'un appareil à l'autre.

Créer un document

  1. Onglet Nouveau document → choisissez le type (Devis, Commande, Livraison, Facture).
  2. Sélectionnez un client existant ou remplissez ses informations.
  3. Ajoutez vos articles avec + Ajouter une ligne — les totaux se calculent automatiquement.
  4. Enregistrer le document pour le garder dans l'historique, puis Aperçu / Imprimer / PDF pour l'envoyer au client.

Enregistrer en PDF ou imprimer — Ordinateur

  1. Cliquez sur Aperçu / Imprimer / PDF.
  2. Dans la fenêtre d'impression, choisissez l'imprimante « Enregistrer en PDF » (ou votre imprimante physique).
  3. Cliquez sur Enregistrer / Imprimer.

Enregistrer en PDF — Android (Chrome)

  1. Appuyez sur Aperçu / Imprimer / PDF.
  2. Dans l'aperçu qui s'ouvre, appuyez sur l'icône d'impression.
  3. En haut, à la ligne « Imprimante », choisissez Enregistrer au format PDF.
  4. Appuyez sur la flèche de téléchargement, puis choisissez l'emplacement pour enregistrer le fichier.

Enregistrer en PDF — iPhone (Safari)

  1. Appuyez sur Aperçu / Imprimer / PDF.
  2. Dans l'aperçu d'impression qui s'affiche, pincez l'aperçu avec deux doigts pour l'agrandir (astuce Safari qui transforme l'aperçu en PDF).
  3. Appuyez sur l'icône de partage (carré avec une flèche) en haut à droite ou à gauche de l'écran.
  4. Choisissez Enregistrer dans Fichiers, ou envoyez-le directement par WhatsApp / Email depuis ce menu de partage.

Utiliser l'app sur plusieurs appareils

Cette application fonctionne entièrement dans votre navigateur, sans connexion internet nécessaire une fois ouverte. Mais elle ne partage pas automatiquement les données entre votre PC et votre téléphone.

Pour transporter vos données : ouvrez l'onglet Paramètres → Exporter une sauvegarde sur l'appareil source, envoyez-vous le fichier (WhatsApp, email...), puis Importer une sauvegarde sur l'autre appareil.

Installer l'app comme une icône sur l'écran d'accueil

Android (Chrome) : menu ⋮ → « Ajouter à l'écran d'accueil ».

iPhone (Safari) : icône de partage → « Sur l'écran d'accueil ».
